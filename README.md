# Ayune Oráculos

Website oficial de Ayune Oráculos, oferecendo leituras místicas e personalizadas de Tarô (online e presencial) e Cafeomancia (leitura ancestral de borra de café de linhagem árabe) em Curitiba, PR.

## Recursos do Projeto

- 📱 **PWA (Progressive Web App):** Suporte a instalação como aplicativo nativo no celular ou desktop, com suporte a carregamento offline via Service Worker (`sw.js`).
- ⚡ **Desempenho e Visual Premium:** Construído com design responsivo (Mobile-First) focado em uma experiência mística minimalista com paleta de cores terrosas inspiradas no café.
- 🎯 **Questionário de Pré-Agendamento Interativo:** Formulário inteligente por etapas para sintonização prévia de energia antes do encaminhamento estruturado para o WhatsApp de Ayune.
- 🔍 **SEO & Otimização Métrica:**
  - Metadados completos Open Graph para compartilhamento em redes sociais.
  - Dados estruturados JSON-LD do Schema.org para indexação enriquecida.
  - Arquivos `robots.txt` e `sitemap.xml` para diretrizes de busca.
  - Arquivo `llms.txt` integrado para conformidade e varredura de Inteligências Artificiais.

## Tecnologias

- HTML5 / CSS3 / Tailwind CSS (via CDN)
- Vanilla JavaScript
- Service Workers & Web Cache API
- Pillow (Processamento de Imagens)
